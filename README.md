## 🧭 选课路径

四条按先修关系排下来的线路。想往哪个方向走，看这条线能接到哪。

- 📡 **通信 / 射频**：信号与系统 → 数字信号处理 → 通信原理 → 天线理论与设计 → 射频电路与系统设计实验 → 通信原理实验
- 🖼️ **信号 / 图像**：线性代数（甲） → 信号与系统 → 数字信号处理 → 数字图像处理 → 人工智能
- 🧠 **智能系统**：C程序设计基础及实验 → 人工智能基础（B） → 离散数学 → 矩阵论 → 人工智能 → 数字图像处理
- 🔌 **电路 / 系统**：电子电路基础 → 数字系统设计 → 电子电路设计实验 I/II → 计算机组成与设计 → 网络基础

## 🗂️ 文件约定

每门课的文件夹名字固定，换一门课也是这几个位置。

- `课程记录` —— 成绩档位、考核方式、投入时间与学习建议
- `复习资料/` —— 历年卷、答案、笔记与知识点整理
- `Project/` —— 课程项目、实验报告、代码与仿真工程
- `课程说明/`、`作业/` —— 课件、任务书与作业要求
- `【参考】` —— 往年资料与同学分享，对照学习用

```text
ZJU-ISEE-IE/
├── 大一上/            # 9 门
├── 大一下/            # 13 门
├── 大二上/            # 14 门
├── 大二下/            # 10 门
├── 大三上/            # 7 门
├── 大三下/            # 8 门
├── docs/              # 课程站
├── tools/             # 重建索引、文件清单与 sitemap：python3 tools/build_site.py
└── README.md
```
