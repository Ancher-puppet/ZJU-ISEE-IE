## 使用指南

| 想做什么 | 去哪里 |
| :--- | :--- |
| 快速了解一门课 | 先读该课程文件夹下的 `课程体验.md` |
| 期末复习 / 刷题 | `复习资料/`：试卷、笔记、答案与题型整理 |
| 做实验 / 课程项目 | `Project/`：报告、代码、仿真工程与实验数据 |
| 看课件 / 作业要求 | `课程说明/`、`作业/` |

**命名约定**

- `课程体验.md`：个人课程体验、考核方式、学习建议与资料索引。
- `【参考】`：参考实现、往年资料或同学分享，便于对照学习。
- `Project/`：课程项目、实验报告、代码与工程文件。
- `复习资料/`：试卷、答案、笔记、知识点整理。
