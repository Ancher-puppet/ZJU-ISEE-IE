# Assignment 2 — MTU 探测实验报告

## 实验目的

通过一系列 `ping` 测试，确定本机到 `www.zju.edu.cn` 之间的路径 MTU（最大传输单元）。

## 实验原理

- 使用 `ping www.zju.edu.cn -f -l xxxx` 命令发送指定大小的 ICMP 数据包。
  - `-f`：设置 IP 头部的 DF（Don't Fragment）标志，禁止路由器对数据包进行分片。
  - `-l xxxx`：指定 ICMP 数据载荷的大小（单位：字节）。
- 当载荷大小超过路径 MTU 减去协议头部开销时，路由器因无法分片而丢弃数据包，ping 测试失败。
- MTU 的计算公式：

$$MTU = 最大不丢包载荷 + IP头部(20字节) + ICMP头部(8字节)$$

## MTU 计算

最大不丢包的 ICMP 载荷为 **1472 字节**，协议头部开销如下：

- IP 头部：20 字节
- ICMP 头部：8 字节
- 总开销：28 字节

$$MTU = 1472 + 20 + 8 = \boxed{1500 \text{ 字节}}$$

## 结论

本机到 `www.zju.edu.cn` 的路径 MTU 为 **1500 字节**，即标准以太网的默认 MTU 值。这表明从本机到目标服务器的整条网络路径上没有额外的隧道封装或 NAT 导致 MTU 减小。
