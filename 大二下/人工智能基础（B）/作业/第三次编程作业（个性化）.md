# 1.问题来源与问题描述
>  问题来源：在智能家居与物联网技术普及的背景下，嵌入式系统的人性化设计成为连接技术理性与生活温度的关键。本次实践源于对现有 Arduino 时钟系统的观察：其虽具备时间显示、温度监测等基础功能，但闹钟机制缺乏对用户实际生活场景的共情 —— 传统闹钟触发后需手动关闭，无法满足现代人 “短暂贪睡再起床” 的普遍需求。

> 问题描述：原有代码（`code.c`）通过 DS1302 时钟模块与 LCD1602 显示屏实现时间管理，结合 LM35 传感器完成温度监测，并利用蜂鸣器实现定时、报警功能。存在以下问题：
> 1. **功能缺失**：原始闹钟触发后仅蜂鸣 5 秒结束，无法通过按键暂停并延迟提醒
> 2. **状态模糊**：LCD 未明确显示 “响铃中” 或 “贪睡中” 状态，用户难以直观感知系统状态
> 3. **交互单一**：触发闹钟后必须等待蜂鸣自然结束，无法通过按键干预（如暂停蜂鸣进入贪睡）
> 现在需要设计一个贪睡闹钟的功能，需要大模型语言辅助优化代码，实现贪睡功能，即在闹钟蜂鸣期间按下按键可以短时停止，并且实现 一分钟后再次蜂鸣的功能，完善状态显示与交互逻辑，提升系统实用性

# 3. 具体操作
## 1.首次提问
### 提问
为我增添一个贪睡闹钟功能，在闹钟蜂鸣时，按下choose、add、minus中的键可以停止蜂鸣，并且计时一分钟，一分钟后闹铃再次响起
```c
void Clock_Alarm() {
	if (hour == alarm_hour && minute == alarm_minute && second == alarm_second) {
		tone(Tone, frequence); 
		lcd.setCursor(9, 1); 
		lcd.print("Ring!!!"); 
		delay(5000);
		noTone(Tone); 
	} 
}
```
### 回答
为了实现贪睡闹钟功能，我们需要在当前的代码中进行以下几方面的修改和添加：
```c
//1. 在全局变量区增加贪睡标志与时间,这些变量将用于跟踪贪睡状态和计时。
bool isSnooze = false; // 是否触发了贪睡功能 
unsigned long snoozeStart = 0; // 贪睡开始时间
```
```c
//2. 在闹钟响起时，检查是否按下了任意按键（`choose`, `add`, 或 `minus`），并触发贪睡模式
void Clock_Alarm() {
  if (hour == alarm_hour && minute == alarm_minute && second == alarm_second && !isSnooze) {
    tone(Tone, frequence);
    lcd.setCursor(9, 1);
    lcd.print("Ring!!!   ");
    delay(5000);
    noTone(Tone);
    
    // 检查是否有按键按下
    if (digitalRead(choose) == LOW || digitalRead(add) == LOW || digitalRead(minus) == LOW) {
      isSnooze = true;
      snoozeStart = millis(); // 记录贪睡开始时间
    }
  }

  // 如果处于贪睡模式，并且已经过了一分钟，则再次触发闹钟
  if (isSnooze && (millis() - snoozeStart >= 60000)) {
    isSnooze = false; // 重置贪睡状态
    tone(Tone, frequence);
    lcd.setCursor(9, 1);
    lcd.print("Ring!!!   ");
    delay(5000);
    noTone(Tone);
  }
}
```
### 结果
- 上传 arduino 板后发现，贪睡闹钟的基本功能无法实现，体现在蜂鸣期间，按下 choose、add、minus 后蜂鸣仍然在继续，并且在 1mins 后也无再次蜂鸣

## 2.第二次询问
### 提问
为什么我在蜂鸣器件按下choose仍然在蜂鸣呢 而且也不显示snooze
### 回答
从你提供的代码来看，问题出在 **按键检测逻辑的位置和时机** 以及 **贪睡状态更新的流程控制** 上。以下是详细的分析和解决方案：
```c
//1.按键检测写在 tone() 和 delay(5000) 中间
	tone(Tone, frequence);
	lcd.setCursor(9, 1);
	lcd.print("Ring!!!");
	delay(5000); // 这里会阻塞程序运行，不会响应按键
	noTone(Tone);
	if (digitalRead(choose) == LOW || ...) { ... }
```
1. `delay(5000)` 是一个阻塞式延时，在这期间无法读取任何按键输入。
	1. 因此即使你按下了按键，也不会进入 `isSnooze = true` 的判断。
2. 按键判断只执行一次
	1. 按键判断只在闹钟触发时执行了一次，而不是在循环中持续检测。
	2. 即使没有 `delay` 阻塞，也难以及时捕捉到按键动作。
3. 显示“Snooze”的逻辑在贪睡状态下被包裹在原闹钟函数中
	1. 贪睡状态下的提示信息 `"Snooze"` 实际上是在 `Clock_Alarm()` 内部再次调用 tone() 时才显示。
	2. 如果没有正确退出第一次闹钟或未清除标志位，可能不会触发第二次显示
   
修改意见如下
```c
unsigned long alarmStartTime = 0;
bool isAlarmRinging = false;
  
void Clock_Alarm() {
  if (hour == alarm_hour && minute == alarm_minute && second == alarm_second && !isSnooze && !isAlarmRinging) {
    isAlarmRinging = true;
    alarmStartTime = millis(); // 记录开始时间
    tone(Tone, frequence);
    lcd.setCursor(9, 1);
    lcd.print("Ring!!!   ");
  }

  // 控制蜂鸣持续时间（5秒）
  if (isAlarmRinging && (millis() - alarmStartTime < 5000)) {
    // 继续蜂鸣
  } else if (isAlarmRinging) {
    noTone(Tone);
    isAlarmRinging = false;
  }
  
  // 检测是否按下任意键以激活贪睡模式
  if (isAlarmRinging &&
      (digitalRead(choose) == LOW || digitalRead(add) == LOW ||
       digitalRead(minus) == LOW)) {
    isSnooze = true;
    isAlarmRinging = false;
    snoozeStart = millis();
    noTone(Tone);
    lcd.setCursor(9, 1);
    lcd.print("Snooze     ");
  }
  
  // 贪睡结束后重新触发闹钟
  if (isSnooze && (millis() - snoozeStart >= 60000)) {
    isSnooze = false;
    isAlarmRinging = true;
    alarmStartTime = millis();
    tone(Tone, frequence);
    lcd.setCursor(9, 1);
    lcd.print("Ring!!!   ");
  }
}
```

建议调试方法：每次按键后添加串口监视器
```c
if (digitalRead(choose) == LOW) {
  Serial.println("Choose pressed!");
}
```
### 结果
- 上传后，闹钟蜂鸣期间，按下 choose、add、minus 后，会停止蜂鸣，但 LCD 显示温度，1mins 后会再次蜂鸣，再次按下仍会正常进入 Snooze 状态，但是 LCD 显示的也就是温度，等下次蜂鸣 5s 后，仍然显示温度，

## 3. 第三次询问
### 提问
功能没问题 但是为什么ring和snooze均不再显示了
### 回答
你的贪睡功能逻辑已经基本正确，但 “Ring!!!” 和 “Snooze” 不再显示的问题，是因为你在 `Clock_Alarm()` 函数中多次调用：
```c
lcd.setCursor(9, 1);
lcd.print("Ring!!!");
```
```c
lcd.print("Snooze");
```
但是这些显示操作只在特定条件下执行一次。由于你没有在后续的循环中持续刷新 LCD 显示，导致这些提示信息被其他函数（如 `Display()`、`GetTemperatures()`）中的 LCD 操作覆盖掉了。
你需要保证在闹钟或贪睡状态下，LCD 上始终显示 `"Ring!!!"` 或 `"Snooze"`，而不是只打印一次。
✨ 方法：添加一个全局标志位，在每次 `loop()` 中判断并刷新显示
```c
// 全局变量
bool showRing = false;
bool showSnooze = false;
```
```c
void Clock_Alarm() {
    if (hour == alarm_hour && minute == alarm_minute && second == alarm_second && !isSnooze && !isAlarmRinging) {
        isAlarmRinging = true;
        alarmStartTime = millis();
        tone(Tone, frequence);
        showRing = true;     // 设置 Ring 标志
        showSnooze = false;  // 清除 Snooze 标志
    }
    if (isAlarmRinging && (millis() - alarmStartTime < 5000)) {
        // 继续蜂鸣
    } else if (isAlarmRinging) {
        noTone(Tone);
        isAlarmRinging = false;
    }
    if (isAlarmRinging &&
        (digitalRead(choose) == LOW || digitalRead(add) == LOW || digitalRead(minus) == LOW)) {
        isSnooze = true;
        isAlarmRinging = false;
        snoozeStart = millis();
        noTone(Tone);
        showSnooze = true;   // 设置 Snooze 标志
        showRing = false;    // 清除 Ring 标志
    }
    if (isSnooze && (millis() - snoozeStart >= 60000)) {
        isSnooze = false;
        isAlarmRinging = true;
        alarmStartTime = millis();
        tone(Tone, frequence);
        showRing = true;
        showSnooze = false;
    }
}
```
```c
void loop() {
  // 刷新 Ring/Snooze 状态显示（放在所有可能修改 LCD 的函数之后）
  if (showRing) {
    lcd.setCursor(9, 1);
    lcd.print("Ring!!!   ");
  } else if (showSnooze) {
    lcd.setCursor(9, 1);
    lcd.print("Snooze    ");
  } else {
    // 如果需要恢复默认状态，可以在这里打印温度等信息
    lcd.setCursor(9, 1);
    lcd.print(Temperatures);
    lcd.setCursor(14, 1);
    lcd.print((char)223);
    lcd.setCursor(15, 1);
    lcd.print("C");
  }
}
```
### 结果
- 上传后，基本功能正常，LCD 显示也正常，但是出现了贪睡闹钟结束后，仍然显示 Ring！！！，而不是正常显示温度

## 4. 第四次询问
### 提问
我在闹铃的时候按了一下choose 为什么非闹铃模式下 本来应该显示温度 但是却显示了ring
### 回答
但这些标志一旦被设置为 `true`，除非手动清除，否则会**一直保持原来的值**。
也就是说：
- 当闹钟触发后，`showRing = true`；
- 按下 `choose` 进入贪睡，`showSnooze = true`；
- 贪睡结束后重新闹钟，再取消闹钟状态；
- 但此时 `showSnooze` 和 `showRing` 并没有被重置为 `false`
- 所以在后续的 `loop()` 中，LCD 依旧显示 `"Snooze"` 或 `"Ring!!!"`，而不是温度信息。

你需要在以下两个时机**清除标志位**：
1. 当贪睡时间结束、闹钟再次响起时
2. 当闹钟完全取消（贪睡后不再重复）时

```c
  // 如果闹钟和贪睡都结束了，清空所有标志
  if (!isAlarmRinging && !isSnooze) {
    showRing = false;
    showSnooze = false;
  }
```
### 结果
- 功能基本完善，上述所呈现的问题也基本解决
