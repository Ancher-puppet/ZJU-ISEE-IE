# 1波导测量系统
1. 驻波输出 有检波计 
2. 末端 短路 全反射 纯驻波 利用驻波测量线  刻度不要超过 1mm 检测出信号即可 
    插入深度，检波匹配（微调旋钮 信号最大的值）0.5 0.6 不要太大 小信号检波
3. 数字万用表测量信号 检波出来是方波的幅度 此时为有效值 而不是峰峰值 用交流档（打开时 默认为直流）
4. 短路块 （最大值为 0.5 比较好一点）找波节点 进而测量波长 称为波导波长（和真空中波长不一样） 用频率计测量频率 验证是否一致 观察示波 一开始是方波 转动频率计 方波会逐渐衰减 
5. 频率计：谐振器 共振时会吸收较多的能量 找到最低点 就是频率中心点 测量此时的频率
